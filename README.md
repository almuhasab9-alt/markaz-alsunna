# مركز السنة للعلوم الشرعية وتأهيل الدعاة — تطبيق الإدارة

## نظرة عامة
- **الاسم**: مركز السنة — نظام إدارة مركز تحفيظ القرآن
- **الهدف**: إدارة شاملة لمراكز التحفيظ: الطلاب، المعلمون، الحلقات، الحضور، الحفظ والمراجعة، التقارير، والتواصل مع أولياء الأمور
- **النوع**: تطبيق ويب PWA (يُثبَّت على الجوال كتطبيق عادي بملء الشاشة)

## الميزات المكتملة ✅
1. **تسجيل دخول آمن** بثلاث صلاحيات: مدير / معلم / ولي أمر (كلمات مرور مشفّرة PBKDF2 + جلسات)
2. **لوحة تحكم المدير اللحظية**: عدد الطلاب والمعلمين والحلقات، نسبة حضور اليوم، رسوم بيانية (Chart.js) لحضور 7 أيام وتوزيع الطلاب على الحلقات — تتحدث فورياً مع كل تسجيل
3. **إدارة الطلاب**: إضافة/تعديل/حذف + ملف كامل لكل طالب (حضوره، حفظه، إنجازاته، شريط تقدم الحفظ من 30 جزءاً)
4. **إدارة المعلمين والحلقات**: إنشاء حسابات معلمين جاهزة للدخول وربطهم بالحلقات
5. **الحضور اليومي السريع**: حاضر/غائب/متأخر/بإذن لكل طالب مع الرجوع لأي يوم سابق
6. **توثيق الحفظ والمراجعة**: من سورة/آية إلى سورة/آية، تقييم (ممتاز/جيد جداً/جيد/يحتاج مراجعة)، ملاحظات لولي الأمر، تسجيل إنجاز إتمام السور
7. **التواصل مع ولي الأمر**: زر اتصال مباشر (tel:) + زر واتساب (wa.me) مع 4 قوالب رسائل عربية جاهزة تُركّب تلقائياً ببيانات الطالب (تنبيه غياب، تقرير أسبوعي، تهنئة إنجاز)
8. **التقارير PDF**: تقرير عام للمركز / تقرير طالب / تقرير حلقة — بشعار المركز في الترويسة، جاهزة للطباعة
9. **صفحة ولي الأمر**: يدخل بحسابه ويرى حضور ابنه وحفظه وتقييماته وملاحظات المعلم فقط
10. **PWA كامل**: أيقونة تثبيت، شاشة بداية بالشعار، Service Worker للعمل دون إنترنت (واجهة مخزّنة)
11. **بيانات تجريبية**: 3 معلمين، 3 حلقات، 20 طالباً، حضور وحفظ 5 أيام، إنجازات

## البنية التقنية
- **Backend**: Hono + TypeScript على Cloudflare Pages (Workers)
- **قاعدة البيانات**: Cloudflare D1 (SQLite سحابية مركزية — مزامنة لحظية)
- **Frontend**: SPA بجافاسكربت + Tailwind CSS + Chart.js + خطوط Cairo/Amiri
- **المصادقة**: PBKDF2-SHA256 عبر Web Crypto API + جلسات HttpOnly cookies

## بنية البيانات (D1)
- `users` — المستخدمون (admin/teacher/parent)
- `teachers`, `circles`, `students` — المعلمون والحلقات والطلاب
- `attendance` — الحضور اليومي (unique لكل طالب/يوم)
- `memorization` — الحفظ والمراجعة والتقييم
- `achievements` — إنجازات إتمام السور والأجزاء
- `sessions`, `settings` — الجلسات وإعدادات المركز

## أهم المسارات (API)
- `POST /api/login` · `POST /api/logout` · `GET /api/me`
- `GET /api/stats` — إحصائيات اللوحة (مدير)
- `GET/POST/PUT/DELETE /api/students` · `GET /api/students/:id`
- `GET/POST/PUT/DELETE /api/teachers` · `POST /api/parents`
- `GET/POST/PUT/DELETE /api/circles`
- `GET/POST /api/attendance?date=` · `GET/POST/DELETE /api/memorization`
- `GET /api/reports/center|student/:id|circle/:id?from=&to=`

## دليل الاستخدام السريع
### إضافة معلم حقيقي
1. ادخل بحساب المدير → صفحة «المعلمون» → «إضافة معلم»
2. أدخل الاسم والبريد وكلمة مرور — المعلم يدخل بها فوراً
3. اربطه بحلقة من صفحة «الحلقات» → تعديل الحلقة → اختر المعلم

### إنشاء حساب ولي أمر
حالياً عبر API: `POST /api/parents` ببيانات `{name, email, password, student_id}` بحساب المدير، أو اربط ولي الأمر من قاعدة البيانات مباشرة (حقل `parent_user_id` في جدول الطلاب).

### تعديل اسم المركز وشعاره
- الاسم: `PUT /api/settings` بـ `{center_name, center_sub}` أو مباشرة في جدول `settings`
- الشعار: استبدل `public/static/logo.png` (وأعِد توليد `icon-192.png` و`icon-512.png`) ثم أعد النشر
